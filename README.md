# Basic-Calculator

# 🧮 Calculator Web Application

## 📌 About the Project

This is a simple, modern, and responsive calculator developed using **HTML, CSS, and JavaScript**. It provides an attractive user interface with colorful gradients, smooth animations, and interactive buttons to perform basic mathematical calculations.

This project was developed as part of the **CodeAlpha Frontend Development Internship** to improve practical frontend development skills.

## ✨ Features

- Addition (+), subtraction (−), multiplication (×), and division (÷).
- Percentage calculations.
- Positive and negative number conversion.
- Clear All (AC) and Delete (DEL) functionality.
- Keyboard support for quick calculations.
- Colorful gradient design with smooth hover effects.
- Responsive layout for desktop, tablet, and mobile devices.
- Instant calculation results and interactive buttons.

## 🛠️ Technologies Used

- **HTML5** – Creates the calculator structure.
- **CSS3** – Adds colors, gradients, animations, and responsive styling.
- **JavaScript** – Implements calculation logic and user interactions.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all three source files are in the same folder.
4. Open `index.html` in your browser or use the Live Server extension.
5. Start calculating!
